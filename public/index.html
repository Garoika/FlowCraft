Подключение FlowCraft MCP к AI-агентам

MCP-сервер FlowCraft активен

Поддерживает Claude Desktop, Antigravity, Cursor, Cline, Roo Code и любые совместимые агенты.

Конфигурация для Claude Desktop / Antigravity / Cursor

Вставьте в файл mcp_config.json или claude_desktop_config.json:

{
  "mcpServers": {
    "flowcraft": {
      "command": "node",
      "args": ["f:/github/FlowCraft/dist/index.js"]
    }
  }
}
